## 🚀 About The Project

**Personal Portfolio Website** is a fully responsive front-end web application designed to showcase my projects, skills, and profile in a clean and professional way.

This project is built using pure **HTML**, **CSS**, and advanced **Media Queries** to ensure a smooth and adaptive experience across all devices.

💻 Open on laptop → 📱 Automatically adapts to mobile → 🎯 Consistent UI everywhere  

The main goal of this project is to create a modern digital presence with pixel-perfect responsiveness and an engaging user interface.

💡 Whether you're a **recruiter**, **developer**, or **visitor**, this portfolio reflects my skills, creativity, and front-end development capabilities.
